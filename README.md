# adon dev · seu ambiente de programação pronto depois de instalar o Linux

Marque o que você vai usar (Git, Node, PHP, Python, Docker…) e o adon dev instala e configura
tudo: Git com seu nome, e-mail e chave SSH, linguagens no terminal, Docker sem `sudo`.

> Em construção. Funciona no Ubuntu 22.04 ou mais novo, Zorin OS 17/18, Pop!_OS 22.04 e Linux Mint 21/22.

## Desenvolvimento

```bash
./dev test               # testes rápidos do motor
./dev docker git,node    # instala de verdade num Ubuntu 22.04 e 24.04 limpos
```

Regras do projeto (todo bug vira teste): [AGENTS.md](AGENTS.md).
